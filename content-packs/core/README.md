# Codekin Core Content

The core content pack describes the 25 Codekin, five ecologies, five qualities, starter choices, Endless Stack rotation, localized creature and skill text, declarative mechanics, and reviewed image assets. Its appearance assets include 25 level-30 evolutions and five level-60 ultimate portraits with transparent themed scenes and character silhouette masks. Version 0.3.9-rc.1 adds Mesh Jelly's bilingual companion greeting, four dialogue lines and three stories in `src/companions.ts`.

Version `0.4.0-rc.1` adds six recruitable expedition Bosses with original glitch portraits, playable skills and mechanics; Fork Queen has a companion profile and three stories. The pack is validated through Codekin Content API version 1 and is bundled into the installable DSH plugin.

An optional creature `companion` profile has a localized greeting, one to eight localized dialogue lines and exactly three stories, each with a localized title and body. The engine controls the 5/20/50 bond thresholds; content cannot grant points or execute code. Profiles are validated before reaching the renderer. This version of the core pack requires engine `>=0.4.0-rc.1 <0.5.0-0`.
